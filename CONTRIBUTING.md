# Contributing / المساهمة

Contributions are welcome when they keep Log Lens small, local-first, portable, and well tested.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and avoid unnecessary runtime dependencies.
3. Add or update tests for behavioral changes.
4. Run `python -m unittest discover -s tests -v` and `python -m compileall -q src tests`.
5. Update both English and Arabic README sections when user-facing behavior changes.
6. Open a pull request explaining the problem, approach, and validation performed.

Please do not commit real production logs, credentials, access tokens, personal data, or generated build artifacts.

---

نرحب بالمساهمات التي تحافظ على المشروع صغيرًا، محليًا، متعدد المنصات، ومغطى بالاختبارات. أضف اختبارات لأي تغيير سلوكي، وحدّث قسمي README الإنجليزي والعربي عند تغيير واجهة المستخدم. لا ترفع سجلات إنتاج حقيقية أو أسرارًا أو بيانات شخصية أو ملفات بناء مولدة.
